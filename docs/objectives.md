# Project Objectives

## Primary Objective

Build a secure and isolated cybersecurity laboratory for learning and practicing web application security.

---

## Specific Objectives

- Configure Oracle VirtualBox.
- Deploy Kali Linux.
- Configure NAT and Host-Only networking.
- Install Docker Engine.
- Deploy OWASP Juice Shop.
- Validate connectivity.
- Perform service detection using Nmap.
- Analyze HTTP traffic using Burp Suite.
- Capture network packets using Wireshark.
- Document the complete implementation.

---

## Learning Outcomes

After completing this project, the following skills were developed:

- Virtualization
- Linux Administration
- Docker Fundamentals
- Network Configuration
- Service Enumeration
- HTTP Analysis
- Packet Analysis
- Technical Documentation
